# HR Attrition Analysis

This project analyzes employee attrition using the IBM HR Analytics Employee Attrition dataset. The goal is to identify key factors contributing to employee attrition and visualize insights to support data-driven HR decisions.

## Project Structure

- **HR_Attrition.ipynb**: Jupyter Notebook containing data exploration, analysis, and visualizations.
- **WA_Fn-UseC_-HR-Employee-Attrition.csv**: The dataset used for analysis.

## Key Features

- Data cleaning and preprocessing
- Exploratory data analysis (EDA)
- Visualization of attrition numbers (bar charts, etc.)
- Insights and recommendations for HR management

## Getting Started

1. Clone the repository or download the project files.
2. Open `HR_Attrition.ipynb` in Jupyter Notebook or VS Code.
3. Run the cells to reproduce the analysis and visualizations.

## Requirements

- Python 3.7+
- Jupyter Notebook
- pandas
- matplotlib
- seaborn

All required packages are listed in the notebook and can be installed via pip if needed.

## Dataset

The dataset is sourced from IBM and contains various features related to employee demographics, job roles, satisfaction, and attrition status.

## Visualizations

- Bar chart of attrition numbers
- Additional charts for demographic and job-related factors
